# A股持仓技术监控

这是一个免费的、只读行情的 A 股技术与行业风险监控项目。GitHub Actions 在每个工作日北京时间 09:00 自动运行，更新日线技术指标、市场代理风险面板，并尝试读取 SEC 公开季度财务数据。行情优先来自腾讯公开日线接口，东方财富接口作为备用，不需要Token或券商账号。

- `output/technical_report.md`：适合直接阅读的最新指标表；
- `output/technical_report.csv`：适合进一步分析；
- `output/risk_dashboard.md`：半导体、A500、黄金等市场代理的收益、波动、回撤和相对强弱；
- `output/fundamental_report.md`：云厂商及美光的公开季度收入、资本开支、现金流和库存代理；
- `data/ohlcv.csv`：历史日线数据。

当前监控标的来自 `config/watchlist.csv`，包括：513310、518880、563360、588710、002312、002326、300153、301330。

## 安全边界

仓库只保存公开行情、技术指标和代码，不保存个人的持仓数量、成本价、账户余额、券商账号或密码。不要把这些私人数据加入公开仓库。

## 使用方法

1. 在 GitHub 新建一个仓库，例如 `a-share-portfolio-monitor`。
2. 将本目录内的全部文件上传到仓库根目录。
3. 上传完成后，代码变更会自动触发第一次运行；也可以进入仓库的 `Actions` 页面，点击 `Update A-share technical report`，再点击 `Run workflow` 手动运行。
4. 以后工作流会在工作日北京时间 09:00 自动更新。A 股节假日没有交易时，可能不会产生新的提交。

## 指标口径

脚本计算 KDJ(9,3,3)、BIAS5/10/20、MACD(12,26,9)、RSI14、MA5/10/20/60、ATR14 和 20 日成交量比，并给出“趋势偏强、短线偏热、弱势暂不加仓”等研究性状态。风险面板进一步计算主题代理的 5/20/60 日收益、20 日波动、60 日回撤和相对 A500 强弱；基本面面板只自动读取标准化公开财务数据，未标准化的 HBM、DRAM、AI应用收入等因子明确保留人工核验状态。

个股使用前复权数据；ETF 采用连续市场价格。588710 的份额调整由公开行情接口的调整序列处理。513310 额外尝试抓取最近可取得的基金净值并计算估算溢价率，但净值日期可能早于市场价格日期，因此不能替代交易所实时溢价数据。

## 本地运行

```bash
python -m pip install -r requirements.txt
python src/market_monitor.py
```

数据接口属于公开行情接口，可能因网络限制、节假日或接口调整而暂时失败；单一标的失败不会阻止其他标的更新，但所有标的都失败时工作流会报错。报告中的历史数据会保留，后续运行成功后自动补齐。
